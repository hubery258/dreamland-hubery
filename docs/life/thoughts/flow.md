# 绵延

> 绵延是时间流动中创造与毁灭形成的艺术。

## 当前理解

绵延并不是保存。时间向前流动时，新的经验不断进入，过去的结构与现在的自己也随之被破坏、重新组成；但这种毁灭并不意味着彻底断裂，新的自己仍然从过去生长出来。所以我现在理解的绵延，大概是在不断的创造与毁灭中仍然保持某种连续。

我愿意接受这种流动。不是因为我能够证明“变化”一定优于“保存”，而只是相比于保存某个恒定的自己，我更愿意走出去，看更多世界，让新的东西进入。

这里又存在一个有趣的问题：

**我唯一不希望改变的，恰恰是我希望自己可以改变。**

## 从哪里想到的

### 《海边的卡夫卡》

佐伯给了这个想法一个很好的反面。

她害怕未来的构建毁灭过去的结构，因此试图永远保存十五岁的爱情。她进入自己的“沙尘暴”，却没有穿过去的欲望，而是选择留在那里，以循环代替绵延。

这让我开始区分：

- 保存与绵延

- 循环与绵延

- 改变与断裂

- 创造与毁灭

也让我意识到，“面对过去”本身未必值得赞美。一个人完全可以始终面对过去，却依然是在逃避未来。

## 还没想明白

- 如果创造必然意味着毁灭，什么东西值得主动保存？

- “连续的我”到底靠什么维持？记忆？身体？叙事？还是仅仅因为我承认过去的人是我？

- 如果未来的我不再珍视“流动”，这算不算对现在这个我的否定？

- 循环是否真的与绵延相反？循环本身会不会也是一种绵延？

- 我现在所说的“绵延”，和哲学中已有的“绵延”概念是什么关系？

## 以后可以继续收集

书、电影、生活经历里，只要再次碰到“变化 / 保存 / 时间 / 自我连续 / 创造 / 毁灭 / 循环”这些东西，都可以扔到这里。

暂时不急着得出最终定义。
