## tableau

见入门教程,感觉是一个很强的数据分析工具啊

> 地图非常适合广泛地可视化你的数据。条形图将帮助我们深入了解细节

- Tableau 按以下顺序应用筛选器：
    1. 提取筛选器
    2. 数据源筛选器
    3. 上下文筛选器
    4. 前 N 个筛选器
    5. 维度筛选器
    1. 度量筛选器
    - 通过**在上下文中添加筛选器**让tableau首先过滤该字段
